LBR CAD Tools - SolidWorks add-in for Longhorn Baja Racing
===========================================================

Install
-------
1. Close SolidWorks.
2. Unzip this whole folder somewhere (for example Downloads). Do not run it
   from inside the zip.
3. Double-click Install.cmd and click Yes when Windows asks for permission.
   If Windows shows "Windows protected your PC", click "More info" and then
   "Run anyway".
4. Start SolidWorks and open a part, assembly, or drawing. The LBR CAD Tools
   tab appears at the top. If it does not, use Tools > Add-Ins and tick
   LBR CAD Tools (both boxes).

Update
------
Close SolidWorks and run Install.cmd from the new version. It replaces the
old one; your settings are kept.

Uninstall
---------
Close SolidWorks and double-click Uninstall.cmd.

Help
----
- What each button does: hover over it, or see the README on GitHub
  (longhorn-baja-racing/lbr-cad-tools).
- Settings: the Settings button on the tab.
- Problems: open an issue on GitHub and attach
  %LOCALAPPDATA%\LBR CAD Tools\BajaAddIn.log
